Reference comparison
OptiLock provides three manually installed gameinfo.gi/video.txt presets and four optional VPKs, under GPL-3.0. The recommended preset has 634 scalar assignments, 544 unique names and 90 duplicated names. Against the current registry, 69 names are not ConVars (four are commands), 31 prohibit gameinfo overrides, 332 are development-only and 116 are cheat flagged; 15 assigned names also appear in the native graphics menu. These categories overlap.

Potato has 616 assignments / 526 names / 90 duplicates; current counts are 68 non-ConVars (three commands), 31 prohibit gameinfo overrides, 333 development-only and 99 cheat flagged. Testing matches the recommended headline counts. A development-only variable exposed by the native video menu can be a legitimate setting; this does not establish normal console access.

The author claims approximately 40% average FPS and 30% 1% low improvement. The repository contains no reproducible scenes, hardware tables, raw frame captures or harness. It has no launch-options recipe, executable installer, hardware detection, backup/rollback or runtime readback. The whole engine-project replacement and creator-specific addon mount are unsuitable for the requested config-only design.

Concrete issues
- cl_async_usercmd_send is defined true then false. Texture mip bias is 8 in gameinfo versus 4 in video; the author requires a Sinner light replacement asset above 4. A forced 256 MB streaming pool ignores this machine's memory budget.
- Current r_shadows is cheat flagged and gameinfo_cannot_override. Native shadow quality 0 means LOW, not OFF. Native texture mip bias 2 / 1 / 0 means Low / Medium / High.
- Particle timescale 1.1, fallback threshold 0 and suppressed effects may change combat cues. FOV 100 / aspect ratio 2.15 changes camera preference and scene load. Audio mixahead .05 versus the nominal .001 is a buffering tradeoff. Guessed audio, AI, physics and network edits lack trace evidence.
- Several purported wins are obsolete names or unchanged defaults. mat_set_shader_quality and enable_priority_boost are command names written as ConVars.
- Four VPKs replace 42 compiled resources. McGinnis and Sinner packages supply different versions of the same global mask; combined behavior depends on mount order. These are replacement game assets. Asset/mod caches and shader caches are different; no shader-cache purge was performed or recommended.

Current config-core.mjs review
No blocking source mapping issue found in the four profiles; all base values are current-menu or shipped-low-preset settings. Review SHA-256: 211F2DF218846E3FB82C9964EAD5A0BDD68E8B8DA5C6140D258E95CCC6BEFBC5.
- Aggressive, FSR1 at .8: the strongest targeted new challenger. It keeps the prior FSR2 baseline's 1536 x 864 scene pixels and changes reconstruction method. Measure throughput and distant-target clarity before selecting it.
- Native at 1.0: 56.25% more internal pixels than .8, with no upscaler. A clarity / CPU-bound comparator; it is not necessarily faster.
- FSR2 Quality at .666667: approximately 30.56% fewer internal pixels than .8. This is a real pixel workload reduction, with conditional GPU benefit and no predicted FPS multiplier.
- FSR3 Quality at .666667: same internal pixel count as FSR2 Quality with another temporal reconstruction mode; compare actual throughput and readability, with no frame-generation claim.
- Sharpening .2 is a readability choice, not established speed gain. Native low-latency mode 1 is already active; the current core preserves the prior UI cap.
- Removing 31 old overrides is compatibility normalization. Some registered non-menu entries might have been honored by the video loader, so restoring defaults can improve or regress performance/appearance. Preserve exact original settings as a fourth comparator and capture them before any write.

The JSON ranks each knob separately for setting validity, conditional workload impact and measured performance evidence. No setting here justifies a 1000x or specific FPS promise. Hidden Panorama controls, guessed threading, particle timing/caps and AI/network/audio edits remain excluded.
